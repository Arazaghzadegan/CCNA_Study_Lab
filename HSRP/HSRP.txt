In this scenario we are going to balance between our router.
in previous scenarios we had one router for backup but we want it to be active in the game while being backup and we will set one router to be main for one VLAN and the Other for it's backup and otherwise. 
** Setting password for this method is not working on packet tracer but I'll leave the command at the end of this note.
**Being Active or Standby will change if one router go out of service and when it's back it will become active again so being active or standby will change all the time.(Active or standby will be set by priority or IP but priority alone cant set active or backup <<all priority is 100>>).
**Virtual IP (VIP) can be set on many interfaces.

======R1 configs=============
en 
conf t
hostname R1 
int g 0/0/0
no sh
ip add 192.168.10.2 255.255.255.0
standby 10 ip 192.168.1.1   ====>(The number after standby represent HSRP group number it doesn't have to be the same on both side but its better to be the same) <the IP next to it is VIP>
standby 10 priority 105    =====> in this case it wont be active if it has become backup until one of them shut down and they negotiate or activating preempt to bring it back by force. 
standby 10 preempt 
standby 10 timers 1 3      ======> first number is for Hello and the second is waiting for other routers to check them.(on both side should be the same) 
standby version 2
do show standby br
end
write

======R2 configs=============
en 
conf t
hostname R2 
int g 0/0/0
no sh
ip add 192.168.10.3 255.255.255.0
standby 10 ip 192.168.1.1
standby 10 timers 1 3 
standby version 2
end 
write
