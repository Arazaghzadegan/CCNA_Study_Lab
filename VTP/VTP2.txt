In previous episode we did all the things manually so in this chapter we are going to make this process auto.
** the condition for running VTP is that your port must be trunk.
** VTP has three versions but in PT we only have Two versions.
** VTP by default is active but we have to enable it manually (check status by show vtp status).
** VTP modes: Server (default), Client, Transparent.
** On client mode, it can only write the changes it can't modify it, on server mode it can do anything, on transparent it wont get updates and wont update others.
** On version 3 you can turn off VTP on all devices or specific device.
** On version 1,2 you can have multiple servers.
