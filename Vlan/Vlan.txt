In this Scenario we are about to learn about VLANs.
One Of VLANs benefits is that you can isolate your end devices.
*You can add each interface manually by going to the specified interface and add them to your desire VLAN or You can Use Range Command and add them.(You don't have to make VLAN first and add interface to it you can add them with range command and the VLAN automatically will be generated.)

======Switch Configs==================
en 
sh vlan br (you can skip this)
conf t 
int range range 0/1 - 3
switchport access vlan 10 ====> It will say the VLAN 10 doesn't exist i created it 
exit 
vlan 10 
name Finance-DEP
exit
interface range fast 0/4 - 6
switchport access vlan 20
exit
vlan 20 
name HR-DEP
exit 
int range fa 0/8 - 9
switchport access vlan 30
exit
vlan 30 
name IT-DEP
exit
int range fa 0/10 - 11 
switchport access vlan 40 
exit 
vlan 40 
name SERV
exit
do wr
