In this chapter we are going to learn about Virtual Trunk protocol (VTP)
in here we have three tiers (Core, Access, Distribution) that we will isolate each tire.(bottom to top LVL)
in access LVL we will isolate the Switches so the end point devices wont receive the packets for update and we will go up.
** You can manually change your VLANs i left it as it is
======SW 1 configs ========
en 
conf t
hostname SW1
int fa 0/1
sw mod acc 
sw acc vlan 10
int fa 0/2 
sw mod acc
sw acc vlan 20 
int gi 0/1
sw mod trunk
end 
write
show vlan br

======SW12 (Access tire)=========
en 
conf t
hostname SW12
int ra gi 1/0/1 - 3
sw mod trunk
exit
vlan 10
vlan 20 
vlan 30 
int gi 1/0/2
sw trunk allowed vlan 30
int gi 1/0/1 
sw trunk allowed vlan 10
end
write 
show int trunk 
=====SW13 (Core tire)=========
en
conf t
hostname SW13
int ra gi 1/0/1 - 4
sw mod trunk
exit
vlan 10
vlan 20 
vlan 30  =====================> we did this part because our acc tire and core tire trunk only allow VLAN1 packets so we have to create them so each device on different places can ping each other.
int gi 1/0/4
sw trunk allowed vlan 10,30 =====> Due to having only two VLANs we blocked passing other vlan packets from this interface. you can do it to other inter faces too. the command is the same.
