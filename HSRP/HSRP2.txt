In this scenario we will run HSRP on Switch Layer 3 instead of routers.
# IPs and configs is like last scenario.
=====SW1 configs========
en 
conf t 
hostname SW1
int g 1/0/1
sw mod trunk
vlan 10
vlan 20
int vlan 10
ip add 192.168.10.2 255.255.255.0
int vlan 20
ip add 192.168.20.2 255.255.255.0
exit
inter vlan 10
standby 10 ip 192.168.10.1
standby 10 pri 105
standby 10 pree
standby 10 time 1 3
standby version 2
exit
int vlan 20 
standby 20 ip 192.168.20.1
standby 20 time 1 3
standby version 2
exit
ip routing   ==============> For layer 3 Switch you have to enter this command otherwise it wont route and it will act as layer 2.
end
write

en

int vlan 10

=====SW3 configs========
en 
conf t 
hostname SW3
int fa 0/1
sw mod acc
sw acc vlan 10
exit
int fa 0/2
sw mod acc 
sw acc vlan 20
exit
int ra g 0/1 - 2
sw mod trunk
