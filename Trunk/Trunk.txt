on some Switches you may encounter an error about trunk for this before you enter the command for trunk you should enter :
switchport trunk encapsulation dot1q
then enter trunk command.



# on switches the packets without VLAN tag is known as default vlan so for security change the native vlan to your desire vlan number by : 
 (on the interface that the trunk is on enter) switchport trunk native vlan (your desire number).

* remember that on both switch the trunk port must be the same
