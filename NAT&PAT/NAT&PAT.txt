In this scenario we are going to learn about NAT & PAT Consider these two network as two different network.


*** Don't forget to determine the inside & outside NAT

======R Company 1 Config============
en 
conf t
hostname C1
int range g 0/0/0 - 1
no sh
exit
int g 0/0/0
ip add 10.10.10.1 255.255.255.0
ip nat inside
exit
int g 0/0/1
ip add 100.100.100.1 255.255.255.0
ip nat outside
exit
ip route 0.0.0.0 0.0.0.0 100.100.100.2
access-list 1 permit 10.10.10.0 0.0.0.255 => to use dynamic NAT you have to have Access list
**ip nat inside source static 10.10.10.10 100.100.100.1 => For static Use This
ip nat pool mynat 100.100.100.0 100.100.100.3 netmask 255.255.255.252 => assume that you bought IP range  
*/* ip nat inside source list 1 pool mynat
*/** ip nat inside source list 1 pool mynat overload (The "Overload" will Use PAT)

======R SP Config=================
en

======R C2 Config=================
en

ip nat inside source list 1 interface g 0/0/1
