# Contributing

Thank you for your interest in this repository.

If you find an error in a configuration, topology, command, or explanation, feel free to open an Issue or Pull Request.

## Contribution Guidelines

- Keep configurations clear and readable.
- Explain the purpose of changes.
- Do not upload real passwords or credentials.
- Do not upload sensitive network information.
- Keep labs focused on CCNA-level networking concepts.
- Include verification commands when possible.

## Pull Requests

Please include:

1. Description of the change
2. Lab affected
3. Configuration changes
4. Verification results
