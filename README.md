# CCNA Networking Labs

A collection of my hands-on Cisco networking labs created while studying for the **Cisco CCNA** certification.

These labs are focused on understanding and practicing networking concepts using **Cisco Packet Tracer** and Cisco IOS commands.

---

## 📚 Topics Covered

- Network Fundamentals
- OSI & TCP/IP Models
- IPv4 Addressing
- IPv6 Addressing
- Subnetting
- Ethernet
- MAC Addresses
- ARP
- ICMP
- TCP / UDP
- Cisco IOS
- Switch Configuration
- Router Configuration
- VLANs
- Trunking
- Inter-VLAN Routing
- STP
- EtherChannel
- Static Routing
- Dynamic Routing
- RIP
- OSPF
- EIGRP
- DHCP
- NAT
- ACL
- CDP / LLDP
- Network Security
- Troubleshooting

---

## 🛠️ Tools

The labs in this repository were created using:

- Cisco Packet Tracer
- Cisco IOS
- Windows
- Linux
- Wireshark
